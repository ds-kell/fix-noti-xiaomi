# Contributing

Open an issue before adding privileged operations. Every write requires a primary source, runtime probe, typed arguments, exact snapshot/rollback, read-back verification, tests, risk label, and a `docs/COMMAND_MATRIX.md` update. Never submit device identifiers, notification content, signing files, secrets, or forum command dumps. Run `./gradlew testDebugUnitTest lintDebug assembleDebug` before a pull request and report physical-device evidence separately from emulator/fake testing.
